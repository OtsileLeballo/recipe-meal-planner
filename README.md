# 🍳 Recipe & Meal Planner

A full-stack recipe management and meal planning application that helps users organize recipes, plan weekly meals, and generate shopping lists automatically.


## ✨ Features

### 📋 Recipe Management
- **Add Recipes** with name, category, ingredients, and instructions
- **View All Recipes** in a clean grid layout
- **Search Recipes** by name, category, or ingredients
- **Filter Recipes** by category
- **Edit Recipes** to update any details
- **Delete Recipes** you no longer need

### 📅 Meal Planner
- **Plan Meals** for all 7 days of the week
- **Select Recipes** from dropdown menus for each day
- **Visual Overview** of your weekly meal plan

### 🛒 Shopping List
- **Auto-Generate** shopping lists from your meal plan
- **Check Off Items** as you shop
- **Clear List** when done
- **Export List** as text (copied to clipboard)

### 🔐 User Authentication
- **Register** new account
- **Login** to existing account
- **Logout** securely
- **Data Persistence** - All data saved in browser's localStorage

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Register a new account
3. Add your first recipe
4. Plan meals for the week
5. Generate a shopping list!

**No installation required - works in any modern browser.**
